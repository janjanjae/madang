# madang — 마당 워커 오버레이

화면 위에 떠 있는 작은 창에 워커(번뜩·몽글·슥슥)를 띄우고 `.claude/team/` 파일 신호만 읽어 상태를 말풍선으로 보여준다. **읽기 전용** — 팀 파일을 쓰지 않는다. 워커 배관(브리프·컨펌 프로토콜)을 건드리지 않으므로 스프린트 중에도 안전하다.

| 말풍선 | 판정 (confirm-protocol Monitor 스크립트와 동일) |
|---|---|
| ✋ 컨펌 대기 / 🚧 막힘 / 💬 논의 요청 | `confirm/{k}.request.md` 있음 + reply 없거나 오래됨. 첫 줄 CONFIRM/BLOCKED/DISCUSS |
| ✅ 답장 처리중 | reply가 request보다 새로움 |
| 📨 브리프 대기 | 보고가 브리프보다 오래됨 (미기동 = 유휴 아님) |
| 💤 유휴 N분 / N시간 | **보고 파일과 세션 기록 모두** 25분 이상 정지 (60분 이상은 시간 단위) |
| ⚙️ 작업중 | 그 외 — 보고를 안 썼어도 탭이 움직이면 작업중 (2026-09-03: `~/.claude/projects/{프로젝트}/*.jsonl` 중 세션명(`-n`)이 이 워커 이름·별칭으로 시작하는 기록에서 **모델이 실제로 산출한 마지막 턴**(텍스트·도구 호출; 사용자 입력·API 오류 턴은 제외)의 시각을 활동 신호로 합산. 마지막 턴이 API 오류면 툴팁에 ⚠️ 표시. 읽기 전용, 팀장 Monitor 스크립트보다 정확) |
| 🛌 휴식 | 브리프 파일 없음 |

- 빌드: `./build.sh` (Command Line Tools의 swiftc만 필요) · 실행: `go-madang` (프로젝트 루트) 또는 `./madang <프로젝트>/.claude/team`
- 조작: 워커 박스 어디서든 드래그 이동 · 마우스 올림 = 그 워커 말풍선 · 한 번 클릭 = 전원 엿보기 2.5초 · 더블클릭 = request/보고 파일 열기 · 메뉴바 아이콘(도담) 또는 **워커 우클릭** = 위치 초기화·잉크·말풍선·종료(상단바가 꽉 차 아이콘이 숨어도 우클릭으로 조작) · `MADANG_SILENT=1` = 효과음 없음
- 분신(`builder2` 등)은 브리프가 24시간 내 갱신된 것만 표시
- **말 없는 워커**(2026-09-03): 평소엔 글자가 없다. 상태는 마스코트로 — 작업중·답장 처리중 = 눈이 커지고 눈동자에 자기 도형(+ 잠에서 깨어 일을 시작하는 순간 한 바퀴 회전), 유휴·브리프 대기·휴식 = 눈 감음, 컨펌 대기·논의 = 실루엣 테두리 호박색 발광 + 말풍선, 막힘 = 적색 발광 + 말풍선. 말풍선은 사람이 행동해야 할 때·엿보기·메뉴 "말풍선 항상 표시"에만. 이름은 툴팁, 분신은 숫자 배지. APPROVE 순간 3초 미소.
- 이름·이모지·그림은 `claude/roster.json`(스킨 표)과 `claude/assets/mascots/*.svg`(rest/smile/sleep/work × light/dark = 40종, `make-mascots.py`로 재생성)에서 읽는다. 잉크는 메뉴바 아이콘(도담) → "마스코트 잉크"(흰색 기본 = 순백/검정/자동). 테두리 없이 본체 반대색의 부드러운 그림자로 바탕과 분리. SVG가 없으면 이모지 폴백
