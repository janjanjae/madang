# madang — 마당 워커 오버레이

화면 위에 떠 있는 작은 창에 워커(번뜩·몽글·슥슥)를 띄우고 `.claude/team/` 파일 신호만 읽어 상태를 말풍선으로 보여준다. **읽기 전용** — 팀 파일을 쓰지 않는다. 워커 배관(브리프·컨펌 프로토콜)을 건드리지 않으므로 스프린트 중에도 안전하다.

상태는 **4신호·5라벨**로 압축된다(2026-09-10, 기존 8종에서 축소 — 경위는 `plans/` 참조):

| 신호 | 라벨 | 판정 (confirm-protocol Monitor 스크립트와 동일) |
|---|---|---|
| 🟠 호박 발광 + 말풍선 | 컨펌 대기 / 논의 | **팀장이 처리** — `confirm/{k}.request.md` 있음, reply 없거나 오래됨, 첫 줄에 CONFIRM 또는 DISCUSS(둘 다 아니면 컨펌 대기 기본값) |
| 🔴 적 발광 + 말풍선 | 사용자 대기 | **사람이 처리** — 위와 동일 조건에서 첫 줄 어디에든 BLOCKED(인사말로 시작해도 잡음) |
| 눈 뜸(안광 유지, 발광 없음) | 작업중 | 그 외 활동 중 — 답장 처리중(reply가 request보다 새로움) · 시동(브리프는 받았지만 탭이 아직 안 움직임) · 순수 작업중을 모두 포함. 탭 활동은 `~/.claude/projects/{프로젝트}/*.jsonl` 중 세션명(`-n`)이 이 워커 이름·별칭으로 시작하는 기록에서 **모델이 실제로 산출한 마지막 턴**(텍스트·도구 호출; 사용자 입력·API 오류 턴은 제외)의 시각으로 판정. 마지막 턴이 API 오류면 툴팁에 ⚠️ 표시 |
| 💤 눈 감음(안광 없음 — 4종 중 유일) | 쉼 / 쉼 N분 | 브리프 파일 없음(쉼, 반투명) 또는 **보고 파일과 세션 기록 모두** 25분 이상 정지(쉼 N분, 60분 이상은 N시간) |

눈은 **쉼일 때만 감고, 나머지 3개 신호는 항상 안광(눈동자 반사광)을 유지**한다(2026-09-10 실사용 피드백 — 컨펌 대기 때 안광이 사라지는 게 무섭다는 반응 반영). 발광 색으로 다급함은 이미 전달되므로 눈 모양은 "떴다/감았다"만 구분한다.

- 빌드: `./build.sh` (Command Line Tools의 swiftc만 필요) · 실행: `go-madang` (프로젝트 루트) 또는 `./madang <프로젝트>/.claude/team`
- 조작: 워커 박스 어디서든 드래그 이동 · 마우스 올림 = 그 워커 말풍선 · 한 번 클릭 = **그 워커만** 엿보기 2.5초(2026-09-10: 말풍선이 한 번에 하나뿐이라 "전원 엿보기"에서 바뀜) · 더블클릭 = request/보고 파일 열기 · 메뉴바 아이콘(도담) 또는 **워커 우클릭** = 위치 초기화·잉크·말풍선·종료(상단바가 꽉 차 아이콘이 숨어도 우클릭으로 조작) · `MADANG_SILENT=1` = 효과음 없음
- 분신(`builder2` 등)은 브리프가 24시간 내 갱신된 것만 표시
- **말 없는 워커**(2026-09-03, 상태 4신호·5라벨 2026-09-10, 안광 상시·말풍선 단일화 2026-09-10): 평소엔 글자가 없다. 상태는 마스코트로 — 쉼(유휴·브리프 없음)만 눈 감음, 그 외(작업중·컨펌 대기·논의·사용자 대기)는 전부 눈이 커지고 눈동자에 자기 도형(안광)이 있는 채로 유지(+ 쉼에서 깨어 일을 시작하는 순간 한 바퀴 회전), 컨펌 대기·논의는 그 위에 실루엣 테두리 호박색 발광 + 말풍선, 사용자 대기는 적색 발광 + 말풍선이 추가된다. **말풍선은 한 번에 하나만** — 우선순위 hover > 클릭한 워커(엿보기) > 사용자 대기 > 컨펌 대기·논의 > (메뉴 "말풍선 표시"가 켜져 있으면) 첫 워커. 이름은 툴팁, 분신은 숫자 배지. 답장 처리중이 APPROVE로 확인되는 순간 3초 미소(상태가 아니라 전이 애니메이션).
- **제목 전문 보기**(2026-09-05 도입, 2026-09-10 개정): 말풍선에 마우스를 올리면 상태 아래에 브리프 제목이 바로 붙고(잘린 한 줄), 1.5초 더 올려두면 그 제목이 **말줄임 없이 여러 줄 전문**으로 바뀐다(최대 4줄, 그 이상은 마지막 줄만 잘림) — 말풍선·패널 높이는 필요한 만큼만 자동으로 커진다. 평소(마우스를 안 올린 상태)의 렌더는 이전과 동일. (2026-09-05엔 이 자리에 "지금 뭐 하나" 요약을 3번째 줄로 덧붙였으나, 같은 폭 상한에 잘려 정보가 실질적으로 안 늘어난다는 실사용 피드백으로 빠졌다 — 대신 제목이 전문으로 보인다.)
- 이름·이모지·그림은 `claude/roster.json`(스킨 표)과 `claude/assets/mascots/*.svg`(rest/smile/sleep/work × light/dark = 40종, `make-mascots.py`로 재생성)에서 읽는다. 잉크는 메뉴바 아이콘(도담) → "마스코트 잉크"(흰색 기본 = 순백/검정/자동). 테두리 없이 본체 반대색의 부드러운 그림자로 바탕과 분리. SVG가 없으면 이모지 폴백
