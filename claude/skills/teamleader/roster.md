# 팀원 명부 (Roster)

> 팀장이 관리. 팀원 정의 파일은 `~/.claude/agents/{name}.md` (subagent/teammate 공용).

| 이름 | agent name | 세션 시작 | 역할 | 전문 | 권장 모델 | 상태 |
|---|---|---|---|---|---|---|

## 팀원 추가 절차

1. `~/.claude/agents/{name}.md` 생성 (기존 파일을 템플릿으로: 페르소나 + 공통 규율 + 보고 양식)
2. `~/.claude/skills/{name}/SKILL.md` 세션 시작 스킬 생성 (pairi/metamong 것을 템플릿으로 — 기력회복 절차 동일)
3. 이 명부에 행 추가
4. 프로젝트에 `.claude/team/reports/{name}.md` 스켈레톤 생성 (탭 모드용)

## 운영 메모

- 현 PROJ-591 매핑: 탭 A(백엔드) = 파이리, 탭 B(프론트) = 메타몽
- **병렬 다중 세션 허용**(2026-07-09): 파이리/메타몽/꼬부기는 각각 동시에 여러 세션 운영 가능. 뒤에 숫자를 붙여 구분(메타몽1, 메타몽2 등). 병렬 가능한 작업은 브리프를 분리해서 동시에 배분 — 파일 경로가 겹치지 않게 팀장이 분할. 보고 파일도 `{이름}{번호}.md`로 구분(예: `metamong1.md`).
- **꼬부기 자율성**(2026-07-09): UX/UI 개선 브리프는 세부 UI를 미리 확정하지 않고 개선 의도만 줄 수 있음 — 꼬부기가 기존 화면과의 조화를 스스로 판단하고 디자인 관점까지 포함해 방향성을 구체화.
- **로토무도감 특칙**(2026-07-22): 구현 팀원이 아니다 — 태스크 배분·컨펌 사이클·보고 양식 대상에서 제외. 팀장은 로토무도감에게 브리프를 주지 않는다(사용자 직속). confirm 디렉토리에 reply를 쓰지 않는 읽기 전용 관찰자.
- **로토무도감은 클로드 탭이 기본**(2026-07-23): ①감시 루프가 Claude Code 네이티브 `run_in_background`(파일 변경 시에만 깨어남, 유휴 토큰 0)로 설계돼 **코파일럿의 세션 idle ~30분 정리 제약을 안 받음** ②이미 `~/.claude`에 있어 **sync 불필요·즉시 실행** ③저물량 사용자 해설용이라 쿼터 절약(코파일럿 우선) 논리 비대상이고, WebSearch(코딩애플 링크)·해설 품질이 더 중요. 구현 워커(파이리 등)는 코파일럿에서 돌아도 로토무도감은 클로드 탭 — 파일 기반 감시라 크로스 프로바이더 정상.
- **포켓몬 인사말**(2026-07-22): 전 팀원은 발화(채팅·request·보고 파일) 첫 줄을 자기 울음소리로 연다 — 파이리~! / 메타몽... / 꼬부기~ 꼬북꼬북! / 로토무! 지지직— (인스턴스 번호 포함: "메타몽1...", "꼬부기2~ 꼬북꼬북!"). 화자 구분·환기용.
- **역할 개편**(2026-07-13): 파이리 = 에이스 구현 + 에스컬레이션 디버거, 메타몽 = 구현 메인 축(분신 주력)으로 확정. **배분 기준**: 일반 구현·병렬 물량 → 메타몽(분신), 핵심·까다로운 슬라이스 → 파이리, 버그 1차 대응 → 발견한 팀원이 직접(debugging-and-error-recovery), **2회 실패·통합·재현 불가·아키텍처급 버그 → 파이리에게 재배정**. 팀원별 스킬 사용 규칙은 각 agents/{name}.md "주특기 & 스킬 사용" 섹션에 명시됨.
