# 팀 빠른 시작 (Codex)

전체 규칙은 팀장 스킬(`$teamleader`)에 있다. 이 문서는 사람이 따라 할 순서만.

## 언제 나누나

- **기본은 나눈다**: 질문 라운드를 돌고 `plan.md`를 승인한 **뒤**, 태스크를 서로 다른 파일 영역으로 갈라 팀원 탭에 준다
- 안 나눈다(예외): 아주 작은 과제 · 태스크가 전부 같은 파일에 몰릴 때 · 마감 직전
- 나눠도 팀원 2~3명까지. 사람이 따라잡을 수 있는 수가 상한이다.

## 순서

1. **팀장 탭** (지금 탭): `$teamleader` → 태스크·파일 영역을 `.team/TASKS.md`에, 브리프를 `.team/briefs/<인스턴스>.md`에 쓰게 한다.
   예: 몽글 = `api/`, 슥슥 = `web/`. 공통 파일(설정·스키마·의존성 목록)은 한 명에게만.
2. **팀원 탭** (`+`로 새 터미널, 탭 이름을 팀원 이름으로):
   ```
   codex
   $builder
   ```

   | 팀원 | 인스턴스 | TOML |
   |---|---|---|
   | 번뜩 | `solver` | `.codex/agents/solver.toml` |
   | 몽글 | `builder` (`builder2` …) | `.codex/agents/builder.toml` |
   | 슥슥 | `sketcher` | `.codex/agents/sketcher.toml` |
   | 조잘 | `narrator` | `.codex/agents/narrator.toml` |
3. **돌기** — 자동 감시가 없으니 사람이 깨운다:

   | 언제 | 어느 탭 | 입력 |
   |---|---|---|
   | 팀장이 브리프를 썼다 | 팀원 | `브리프 확인해` |
   | 팀원이 "컨펌 대기"라고 했다 | 팀장 | `컨펌 왔나 봐` |
   | 팀장이 reply를 썼다 | 팀원 | `reply 확인해` |
   | 한동안 조용하다 | 팀장 | `유휴 점검해` |
4. **마무리** — 팀장 탭에서 `plan.md`에 검증 결과·남은 한계 정리 → 새 탭에서 `$defense-drill`로 이해 질문 + 모범 답안을 우선순위 순으로. 구조 설명만 필요하면 조잘(탭 또는 "narrator 에이전트로 …").

## 서버

서버는 팀원 탭이 아니라 **전용 터미널**에서 `0.0.0.0`에 띄우고 닫지 않는다. 여러 팀원이 각자 서버를 띄우면 포트가 겹치고 메모리를 먹는다 — 포트는 브리프에 적어 나눈다.
