
## 제한 환경 규칙 (감독·폐쇄 환경용 — `install.sh --restricted`)
- `git push`·PR·원격 전송을 하지 않는다. 커밋은 로컬까지만. (훅이 `git push`를 막는다)
- 작업 파일·결과물을 외부로 보내거나 공유하지 않는다. 공개 저장소 clone·패키지 설치처럼 **가져오는** 것만 한다.
- 개인 API 키나 다른 AI 모델·서비스를 연결하지 않는다. 세션에서 고른 모델을 그대로 쓴다(서브에이전트도 상속).
- 플랫폼이 관리하는 설정·연결 프로세스를 수정하거나 종료하지 않는다. 전역 설정(`~/.codex` 등)은 건드리지 않는다.
- 도구(Codex 등)를 업데이트하지 않는다. 업데이트 권유가 떠도 무시한다.
- 키·토큰·비밀번호를 파일·로그·출력에 남기지 않는다.
- 토큰을 아낀다: 같은 요청을 반복하지 않는다 · sleep/폴링 루프로 기다리지 않는다 · 서브에이전트는 꼭 필요할 때만 · 큰 출력은 줄여서 본다.
- 서버는 별도 터미널에서 `0.0.0.0`에 바인딩하고, 서버가 도는 터미널은 닫지 않는다. 안 쓰는 프로세스는 끈다(메모리 초과는 본인 책임).
