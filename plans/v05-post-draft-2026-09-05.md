## 한국어 초안 A (블로그/SNS, ~800자)

혼자 Claude Code를 쓰다 보면 두 가지가 자꾸 걸렸다. 긴 작업이 도는 동안 지금 뭘 하고 있는지 화면 밖에서는 안 보였고, 검증 없이 커밋이 그냥 나갔다. 그래서 역할이 다른 에이전트 다섯을 터미널 탭마다 띄우고, 파일로만 조율하는 팀을 만들었다. 이름은 마당(madang) — 팀원이 모여 일하는 앞마당이라는 뜻이다.

팀장 도담이 배분하고, 번뜩(깊이 — 어려운 문제 하나를 끝까지)·몽글(넓이 — 같은 모양의 태스크 여럿을 병렬로)·슥슥(시안 — 화면이 필요할 때 프로토타입)·조잘(해설 — 비개발자에게 쉽게 설명)이 각자 탭에서 일한다. 커밋 전엔 컨펌 파일을 쓰고 팀장 승인을 기다리게 훅으로 막아 뒀다. 화면 위엔 작은 워커 오버레이가 떠서, 각 팀원이 지금 컨펌을 기다리는지·막혔는지·놀고 있는지를 실루엣 색으로 보여준다. 이름·그림 전부 자작이고 CC BY 4.0이다.

echo 'source '"$PWD"'/claude/shell/go-functions.zsh' >> ~/.zshrc

## 영어 초안 (~150 words)

madang ("courtyard" in Korean) is a Claude Code setup for running five agents with distinct roles across parallel terminal tabs, coordinated entirely through files. Working alone with Claude Code, two things kept bothering me: I couldn't tell what a long session was actually doing, and commits went out without review. madang fixes both — a small always-on-top overlay renders each teammate's live state (waiting for approval, blocked, idle) from plain files under `.claude/team/`, and a commit-gate hook blocks `git commit` until the lead approves. One lead (dodam) plus four teammates: solver (depth — one hard problem at a time), builder (breadth — many similar tasks, with clones), sketcher (UI prototypes in isolated worktrees), and narrator (read-only explainer). Mascots are original, CC BY 4.0.

```
git clone {repo-url} && cd madang
./install.sh
```

Code is MIT. Running this solo — issues and PRs welcome, except new personas.
